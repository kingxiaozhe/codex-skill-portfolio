# Self-hosted font sources

- Geist Sans and Geist Mono are published by Vercel under the SIL Open Font License 1.1: <https://github.com/vercel/geist-font>

The bundled web fonts are used only by the static portfolio website. Chinese glyphs use the visitor's native CJK system font for clarity and loading performance. The full Geist OFL 1.1 text is stored beside this file in `OFL-1.1.txt`.
